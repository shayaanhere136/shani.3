# Smart Healthy Tiffin

A static, GitHub Pages-ready landing page for Smart Healthy Tiffin — a modern healthy food and tiffin delivery concept for Islamabad and Rawalpindi.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root (`/`), then save. This site uses no build step.

## Before launch

The product cards intentionally show prices as **to be announced** because the supplied specification says not to invent prices or nutrition values. Replace the sample product content, images, contact details, policies, delivery zones and payment flow with verified business data before launch.
